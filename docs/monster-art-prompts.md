# Monster art prompts

One prompt per monster, in one consistent style. Generate each at 1024x1024, save as WebP in `public/monsters/<id>.webp`, then add the id to `public/monsters/manifest.json` (a JSON array of ids). The app swaps in the artwork automatically.

Regions: Ravenmoor, The Emberfen, The Glasswood, Frostmere.
